# 制作定位：平台、内容、风格与时长

在完整制作或改变制作定位时使用；不把简单换字、转录或已确认项目的局部修改变成重新填写问卷。此层给后续决策设方向，不是平台运营研究，也不授予改写、发布或额外生成权限。

## 1. 先分清维度

从用户要求、素材和既有项目提取下列信息，区分“用户指定 / 已确认沿用 / 建议待确认”。平台未知可先做通用方案；会影响实际构图、语言或剪辑的缺项，在对应制作前确认。用户授权自主决定时写出理由，不重复追问。

| 维度 | 需要判断 | 影响什么 |
|---|---|---|
| 受众与目的 | 面向谁、已有知识、地区/语言；教学、解释、信任、娱乐或转化 | 术语解释、信息取舍、开场及结尾；不默认营销CTA |
| 平台与发布形式 | 抖音、TikTok、小红书、B站、Instagram、Facebook或其他；短视频、完整教程等具体形式 | 输出画幅、观看尺寸、字幕安全区、语言与必要交付物 |
| 内容与选题角度 | 教程、测评、案例、观点、故事、产品/方案；本片具体回答什么 | 叙事骨架、真实证据、图解需求，不只是贴一个“知识类”标签 |
| 风格 | 干净教学、轻综艺、故事纪录、设计展示、专业商务等；强度及禁用项 | 镜头运动、花字、声音、色彩与阅读停留 |
| 时长与结构 | 硬性上限、目标范围或完整保留；单一主题短篇或章节式长片 | 能承载的信息量、章节和删减方案 |

平台不是风格：不规定抖音必快切、TikTok必英文、小红书必卡片、B站必玩梗，也不把 Instagram 与 Facebook 当成同一套输出。用户说“B站风格”等模糊要求时，结合内容给出可执行解释；差异重大时问更偏教程、故事还是综艺，必要时请用户给参考。地区、语言和本地案例单独判断，翻译不等于完成本地化；翻译配音须另获授权。

不凭记忆写死平台时长上限、分辨率要求、安全区像素或流量规律。制作平台专用输出时按具体发布形式核对当前官方规格，并在项目记录来源/日期；暂无法核实时标记待核验，可做保守预览，不称已符合发布规范。无需具体平台规格的通用剪辑不强制联网研究。热点或算法判断需另有当前证据，不承诺播放量。

## 2. 把定位转成制作决定

在 project.md 写一段简短“制作定位”：上述有效选择、确认状态，以及它们对下列环节的实际影响。未知项按需列出，不预填假数据；不要新增与 visual-plan.json 并行的精确时间线或修改既有校验协议。

- **结构与剪辑**：开场如何建立关注、哪些信息必须保留、何处给证据/例子、如何结束。短篇可围绕一个承诺展开，但不强制“三秒钩子”。已有录音保持原意与授权剪辑范围，不能以平台偏好为由私自重排、删句、变速或新配音。
- **画面与声音**：人物/演示的主要构图、字幕层级、画面信息密度、主动作强度、图解需求、哪些段落应静止；BGM/SFX使用范围与禁用项。风格不等于固定效果数量。风格强度同时决定定制 MG 灵感条目的可用范围：`energy=强` 的炫技类参考只在定位允许的开场注意点或片尾落版使用，讲解段落以克制/中等为主（见 [mg-prompt-patterns.md](mg-prompt-patterns.md)）。
- **交付**：只列用户要求的版本、画幅、语言及附属输出。提到多个平台先区分“一版兼用”还是“分别改版”，不能自动制作六套视频、封面或发布文案。

内容类型提供起点而非固定模板：教程优先真实操作与可复现步骤；测评优先条件与证据；案例保留素材到结果的真实对应；观点区分判断和事实；故事保留铺垫、转折与情绪；产品/方案说明问题、机制与适用边界。资料不足时标缺口，不为适配选题编造效果或数据。

## 3. 短篇与章节长片

不设一个通用秒数把所有平台分成“长/短”。根据目标时长、内容复杂度与观看目的判断。

- **短篇**：围绕有限核心信息组织开场、证据/示例和落点；压缩冗余须在已授权范围内。先区分文件总长与有效讲话、必要停顿和读图时长，不能只凭录音文件长度断言目标不可能，也不能默认删尽所有停顿。确实与目标时长冲突时，提供延长、授权删减或拆分等可行取舍，不能靠全片加速硬塞。
- **章节长片**：先组织全片论述及章节依赖，再做局部镜头。每章明确问题、证据/演示、阶段落点和承上启下；按内容安排回顾、完整操作、安静阅读与情绪释放，不每章机械重播强开场。先试一个代表章节检查风格与渲染成本，再按已确认方案制作其余部分。
- Shotcraft 负责局部聚焦、章节转场、成果展示等；长片不持续堆高能动效，也不是把短片配方循环拉长。精确帧只落在主计划，章节记录引用 shot_id。
- 从长片另剪短版或从短片扩成教程是新的内容取舍，不能仅通过改尺寸或重复镜头完成。用户已明确要求的版本视为范围已确定，不重复批准；只确认尚未确定且影响原意的选段、重排或扩写策略。只重排版且声音不变时复用旁白；删改内容/翻译配音时更新相应版本与时间映射。

## 4. 综艺作为可调包装层

先识别素材中真实存在的犹豫、意外、反差、反应和笑点，再判断是否值得强调。轻综艺可用少量反应推近、定格、花字、视觉比喻和短音效；没有合适点可保持克制，不要求每隔几秒制造笑点。

原话字幕与编辑点评在措辞/样式上区分，不能将吐槽当人物原话。重放、定格或插入反应改变时长时重新对齐音画；不能把别处表情拼成虚假的现场反应、用笑声伪造观众反馈，或以搞笑为由改变人物意思。无授权的音乐、影视梗素材和第三方人声不直接加入；不凭“综艺风”推定可付费下载或生成。专业/敏感解释段让包装退后，优先听清与看懂。

## 5. 冲突处理与传递

用户明确约束、事实真实性与可读性优先于风格建议；平台硬规格冲突先确认发布形式/版本，不静默改内容。没合适配方时回到表达缺口判断 MG，不能用“这是小红书/B站”作为定制或跳过选库的唯一理由。

将定位连同原文、选镜头依据和主计划交给制作与审查者。验收不仅看有无写平台名，还要检查结构、语气、声音、构图、章节和时长是否真正响应定位；未知规格和未经实际测试的平台分开声明。工作流升级不自动重剪用户已经接受的旧视频。
