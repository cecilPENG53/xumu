# 验收、恢复与交付

## 四道检查

1. **内容与来源**：对应原口播；数字有依据；截图确实展示所说功能；故事再现不冒充纪实；模型没有增加未授权人物/品牌/信息。动态段落有内容到候选镜头的选择依据，定制 MG 有具体表达缺口；不是制作完基础卡片后补写理由。
2. **单镜头**：检查实际媒体解码、帧率、画幅、长度；关键帧覆盖入场/峰值/落定；中文字形、换行、安全区、遮挡、透明边缘和末帧无冻结错误。对照 Shotcraft 时实际读取准确实现；要求动态复现时看动态，不只看海报。
3. **时间与声音**：运行 plan_tools 的 ready 检查；目标时刻误差检查到帧；口播没有剪词、重复/缺失；字幕对应剪后时间；SFX 进入了最终混音；BGM 不盖人声；最终响度与峰值实测。
4. **整片**：从实际渲染抽查每个切点前后、开头结尾与中段，并连续看/听节奏。核对信息递进、动静交替、全貌/细节、人物回归、语义落点、阅读停留和转场依据；强动作不连发抢叙事、基础卡片不无理由重复。无人物模式画面全覆盖；人物模式没有误盖脸；全片字幕只一套。镜头单测通过不能代替整片验收。

`verified` 只能在上述对应检查完成后标记；存在文件、通过编译、工具返回 job ID 或单张静帧都不代表成片已验证。

## 镜头意图验收

- 对照 [制作定位](production-profile.md) 检查受众/目的、内容、风格和时长是否落实：开场与结尾、证据密度、字幕/构图、动静与声音，而不只是标注平台名。章节长片检查章节衔接、完整演示及持续阅读；综艺包装检查原话/点评区分、反应真实性与是否干扰理解。按各实际输出检查尺寸、语言、时长和已核验的平台形式规格；未核验项不宣称发布就绪。多版本分别检查，不把某一版通过外推给其他版。
- 对照 shot-selection.md 或 project.md 的选择记录，逐 shot_id 检查选定卡/变体是否真实进入成片；翻滚、推近、擦除等用户指定动作不能被相似文案加淡入替代。
- 同时对照准确 demo 与实际查看过的动态参考；检查关键时值、遮罩、路径与落定。样片未看或缺失时单独标无法验证，不能因代码存在就声称还原通过。
- 配方适配、配方加原创图解、纯定制 MG、直接保留原片分别如实记账；不按配方数量判断成功，也不以“用了一个配方”代表满足整片镜头设计诉求。
- 如未落实用户指定动作，回到方案说明原因并取得必要确认，而不是把“能播放”的技术检查当创意验收。
- 随附 plan_tools 不验证上述创意/参考匹配；需人工式导演判断。旧版已确认项目不因 Skill 升级自动返工，下一次用户要求新制作或改版时应用新流程。

## 独立审查

已确认作品只改局部文字、颜色等，且无时序或创意变化时，可复用仍适用的定位、参考与旧验收证据，不因历史工程有多个动画就重新启动完整选库/独立创意审查。仍检查改动帧、受影响布局、接缝及新合成文件的解码、时长和声音保留情况；记录新版哈希及证据适用范围，不能把旧成片通过直接当作新文件通过。影响扩散、改变结构/时间线或新增多个动画时扩大验收并按下述条件独立终检。

实际制作涉及多个动画或 Shotcraft 成片交付，且有合法可用的独立 Agent 时，提供最新成片、旁白/原文、已确认简报、镜头候选与 MG 决策、全片节奏说明、主画面计划、素材来源、卡片及对应代码/参考样片做独立终检；不要传“应该通过”的暗示。问题附实际帧号/截图和影响。

没有独立审查能力时，如实记录未完成独立审查；仍做自检，可交待审预览，不冒充已完成该门槛。只讨论方案、创建 Skill 或交接提示词不触发视频成片独立验收。

## 故障与续作

- 每次修改只重做受影响的镜头，最后整片重合成并检查接缝。时间线变更引发版本失配必须处理，不通过仅改 revision 掩盖未检查素材。
- 本地自检修复最多连续 3 轮；外部生成按 production.md 的次数及预算上限。持续失败后报告具体镜头、证据与可选处理，不无限重跑或自行删掉重要内容。
- `project.md` 写已确认策略、当前 revision、完成/等待的镜头、实际工具版本、下一步和阻塞项。中断后先核对这些状态和文件，不重转录不变的原素材，也不声称未执行的后台任务继续运行。
- 外部回传文件先验证 shot_id、版本、长度、画幅、声音和内容，旧版结果不能自动装进新版时间线。

## 交付层级

- 方案：简报、剪辑策略/画面安排，明确尚未制作。
- 外部制作包：提示词、参考文件、任务编号和回收要求，明确等待生成。
- 预览：能播放的完整低成本成片，列出确实未过的检查或待确认点。
- 正式交付：验证后的成片、使用的项目/时间线、必要素材来源、验收记录；有 BGM 且用户需要后配乐时可另交无 BGM 但保留 SFX 的版本。

用用户看得懂的话说明结果和限制；不要交付 API key。未经用户请求不发布、提交到作品展示页或导出到外部服务。需要工作台或剪映工程时单独核对能力；Windows 剪映导出不以作者“实现但未真机验证”的状态作为通过证明。
