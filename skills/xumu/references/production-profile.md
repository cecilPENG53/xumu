# 制作定位：平台、内容、风格与时长

完整制作或改变定位时使用。它为后续决策定方向，本身不授予改写、发布或额外生成的权限。

## 1. 五个维度

从用户要求、素材和已有项目中提取，标注"用户指定 / 已确认沿用 / 建议待确认"。会影响构图、语言或剪辑的缺项，在对应制作前确认。

| 维度 | 判断什么 | 影响什么 |
|---|---|---|
| 受众与目的 | 面向谁、已有知识、地区与语言；教学、解释、建立信任、娱乐还是转化 | 术语解释、信息取舍、开场与结尾；CTA 按目的决定 |
| 平台与发布形式 | 抖音、TikTok、小红书、B站、视频号、YouTube、Instagram 等；短视频还是完整教程 | 画幅、观看尺寸、字幕安全区、语言、交付物 |
| 内容与角度 | 教程、测评、案例、观点、故事、产品方案；这一期具体回答什么 | 叙事骨架、证据需求、图解需求 |
| 风格 | 画面语言（见 [风格与技术栈](style-stack.md)）、包装强度、避开项 | 绘制技术、镜头运动、花字、声音、色彩、阅读停留 |
| 时长与结构 | 硬上限、目标范围或完整保留；单主题短篇还是章节长片 | 信息量、章节、删减方案 |

平台与风格分开判断：同一平台容纳多种风格，同一风格可发多个平台。用户说"B站风格"这类模糊要求时，结合内容解释成具体的画面语言与节奏；差异大时问清更偏教程、故事还是综艺，或请用户给参考。本地化单独判断，翻译配音另需授权。

平台规格（时长上限、分辨率、安全区）与流行趋势按发布时的官方信息核对，记录来源和日期；暂时核实不了就标"待核验"，先做保守预览。通用剪辑不需要专门查规格。播放量不做承诺。

## 2. 把定位变成制作决定

在 project.md 写简短的"制作定位"：有效选择、确认状态，以及对下列环节的影响。未知项列为待定。

- **结构与剪辑**：开场如何建立关注、哪些信息必须保留、证据与例子放在哪、如何收尾。短篇围绕一个承诺展开，开场形式按内容决定。已有录音在授权范围内剪辑，保持原意。
- **画面与声音**：人物与演示的构图、字幕层级、信息密度、动作强度、主风格与避开清单、需要静止的段落、BGM/SFX 范围。风格强度同时决定定制 MG 灵感条目的可用范围：`energy=强` 的炫技类参考只在定位允许的开场注意点或片尾落版使用，讲解段落以克制或中等为主（见 [mg-prompt-patterns.md](mg-prompt-patterns.md)）。
- **交付**：只做用户要的版本、画幅、语言与附属物。涉及多个平台时，先确认"一版通用"还是"分平台改版"。

内容类型是起点：教程重真实操作与可复现步骤；测评重条件与证据；案例保留素材到结果的对应；观点区分判断与事实；故事保留铺垫、转折与情绪；产品方案讲清问题、机制与适用边界。资料不足就标出缺口。

## 3. 短篇与章节长片

按目标时长、内容复杂度与观看目的判断，不设统一的秒数线。

- **短篇**：围绕有限核心信息组织开场、证据与落点。区分文件总长与有效讲话、必要停顿、读图时间；确实与目标时长冲突时，提供延长、授权删减或拆分的选择，语速保持自然。
- **章节长片**：先组织论述与章节依赖，再做局部镜头。每章有问题、证据或演示、阶段落点与承上启下；按内容安排回顾、完整操作、安静阅读与情绪释放。先做一个代表章节验证风格与渲染成本，再推进其余章节。动效强度随章节作用起伏；Shotcraft 用于局部聚焦、章节转场与成果展示。
- **改版**：长剪短、短扩长都是新的内容取舍。用户明确要求的版本直接做；会影响原意的选段、重排、扩写再确认。只改排版且声音不变时复用旁白。

## 4. 综艺包装层

先找素材中真实存在的犹豫、意外、反差、反应和笑点，再决定是否强调。轻综艺可用反应推近、定格、花字（做法见风格目录 `variety-caption`）、视觉比喻和短音效；没有合适的点就保持克制。

- 原话字幕与编辑点评在措辞和样式上区分。
- 重放、定格、插入反应后重新对齐音画；反应镜头取自真实现场。
- 音乐、影视梗素材、第三方人声需有授权。
- 专业或敏感段落让包装退后，优先听清、看懂。

## 5. 冲突与传递

优先级：用户明确约束 > 事实真实性 > 可读性 > 风格建议。平台硬规格冲突时，先确认发布形式。把定位连同原文、选镜头依据与主计划一起交给制作与审查。工作流升级不追溯重剪用户已接受的旧视频。
