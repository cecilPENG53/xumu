# 输入与旁白

## 三种入口

### 视频

读当前 Video Use 的 SKILL.md 后使用它的转录/剪辑功能，必要时先读 helper 的 `--help` 和实现，避免复制过期示例选项。探测分辨率、时长、帧率、声道和旋转。混合帧率素材先确定交付帧率；竖屏构图不能只缩放横屏。

逐字原样 ASR 保留停顿、语气词和重录信号；检查本地缓存，源文件变化才重转录。云端转录需已有服务授权，不输出凭据。保留原素材路径、片段实例 ID、原片起止和剪后起点。剪辑点对齐词边界、留合理边缘并做短音频淡入淡出，不能剪断一个词。

原片画面可作为全片背景，因此允许只对局部时间安排覆盖。主剪辑版本锁定后生成主时间线字幕和 `visual-plan.json`。

### 音频

确认“原声保留”或用户允许的剪辑策略；语气、节奏和人物意图不得为追求紧凑被消除。完成转录、选段和短淡入淡出后生成旁白母带，复核新时间戳。

可复用 Video Use 的转录/剪辑思想，但先检查 helper 是否支持纯音频；其视频提取与底片合成流程不能默认接收音频。必要时独立使用 FFmpeg 提取并拼接音频片段，保留对应的映射和原文件。

画面需要覆盖全片：连续插画场景、录屏、图解、设计过的背景加文字都可以，不强迫每句更换镜头。不自动添加数字人。导出时母带是唯一主旁白；B-roll、模型生成片段默认不把自带人声混进来。

### 文案

先判断它是“待改写脚本”还是“已有录音的逐字稿”。默认保留观点、事实和顺序；语句重写或扩充故事需用户授权，屏幕短文案另存。

- 使用原声：可以先做结构和粗分镜，等用户录音后对齐。已有转录稿但缺少原音频，不能编造真实时间戳。
- 合成旁白：确认声音、语言、专有名词读法和预算。可先试听一小段；已有明确选择不重复问。不默认克隆用户或第三方声音。生成后检查错读、漏句，再锁时间。
- 无旁白：可制作字幕/音乐驱动视频，按实际阅读和动作时长排帧。记录 `narration.kind=none`，不要再以“缺音频”为阻塞。

用估算语速得到的时长只能标注为草案。`--ready` 前，实际音轨和帧级计划必须匹配；字幕时间从音轨对齐获得，不从字符数假装推导词级时间。

## 时间线修订

1. 来源文件、转录缓存分别保留；实际旁白文件变更也视为时间线需复核的变更。
2. 片段重复出现时分配不同实例 ID。简单硬切的原片→输出映射可用差值；变速、重叠转场或拆分跨段动效必须显式重新映射。
3. 新增/删减/变速/重排后更新 timeline.revision；重新计算受影响的镜头、字幕和 SFX。独立局部动画可复用，但必须重新检查与新窗口的长度及语义同步，不自动改标为通过。
4. 不改变时间线的改色、局部文字修改，只更新相应资产和验收记录，不重做转录。

## 最少启动问题

从已知信息填充，不机械地问全套：输入模式；按 [制作定位](production-profile.md) 判断的受众/目的、平台与发布形式、内容、风格和目标时长；必须保留内容；声音选择；外部生成预算/是否允许上传。已确认项沿用，只有缺项会实质改变制作时才问。定位不能代替原声剪辑或配音授权；缺少外部模型时仍可推进不依赖它的规划和代码镜头。
