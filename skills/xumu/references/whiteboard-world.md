# 白板一镜到底（whiteboard-world）

风格目录中 `whiteboard-world` 的完整做法与模板。来源是《一人公司介绍》7 分 41 秒成片（HyperFrames 0.8.81，1920×1080；模板演示在 0.8.166 回归验证一致）。模板在 `assets/templates/whiteboard-world/`：

| 文件 | 作用 |
|---|---|
| `template.html` | HyperFrames 页面骨架：画笔手、多镜头渲染循环、视频卡片跟随白板、圆形人像 |
| `wb_lib.py` | 构建库：世界、站点、镜头、手写字、描线、图标、显示器衔接、视频卡片、录屏镜头、人像 |
| `example_build.py` | 可运行的 16 秒演示，覆盖全部机制；新项目先跑它确认环境 |

目前只验证了横屏 1920×1080。竖屏需要改模板里的画布尺寸、镜头换算常数和人像位置，并重新验证。

## 1. 核心概念

- **世界（world）**：一段白板 = 一块很大的画布（默认 8000×3200），配一台虚拟镜头。同一段里的所有内容都画在这块布上，镜头在上面移动，形成一镜到底。
- **站点（station）**：世界里的一个内容区，`comp.station(dx, dy)` 设定偏移。多个站点呈之字形排开，站点之间用甩镜加灰色手绘箭头连接，段尾整体拉远看到全部站点。
- **镜头关键帧写成"要框住的矩形"**：`(时间, (x, y, 宽, 高), 时长, 运动类型)`，库自动换算成缩放和位移（`s = 1920 / 宽`）。矩形取 16:9，否则画面会变形取景。
- **擦痕**：世界里自动散布淡灰擦痕，镜头在大片白底上移动时观众有参照。

## 2. 镜头运动

| 类型 | 用途 | 缓动 | 动态模糊 |
|---|---|---|---|
| `set` | 瞬间就位（段首，或停在显示器上等待拉出） | — | — |
| `push` | 推近重点 | power3.inOut | — |
| `pan` | 平移到相邻内容 | power2.inOut | — |
| `whip` | 甩到下一个站点 | expo.inOut | 7px |
| `pull` | 拉远看全貌 | power2.inOut | — |
| `dive` | 冲进手绘显示器 | power4.in | 5px |
| `emerge` | 从显示器里拉出来 | power3.inOut | 3px |

- 镜头始终带轻微手持晃动（缩放 ±0.8%，位移几像素），白板不会显得死。`dive` 时晃动降到 0，`emerge` 后恢复，保证显示器画面和真实录屏首帧、末帧完全对齐。
- 镜头力度要强：推、甩、拉都要看得出来，段与段之间不硬切。
- 动作选择遵循 [解说语法](explainer-grammar.md#4-动作就是语义)：推近 = 强调，拉远 = 全貌，甩 = 同层级跳转，下潜 = 从概念进入实操。

## 3. 画笔手与手绘元素

- `note(x, y, 文字, 时刻)`：手写字从左到右显现，画笔手沿文字移动。
- `doodle(路径, 时刻, 时长, 样式)`：描线画出，画笔手沿路径走。样式 `k`（黑）、`k blue`、`k green`、`k red`、`k grey`，加 `thin` 变细。
- 画笔手的位置完全由时间线时间计算，任何一帧都能单独渲染；两笔间隔 ≤1.1 秒时在两笔之间滑动，更久就移出画面。
- 描线开始前先隐藏线条，避免圆头线条提前显示成一个点（模板已处理）。
- 图标库（`p_*` 函数，返回手绘路径）：箭头、放大镜、文档、浏览器、地图钉、勾框、对勾、对话气泡、表格、柱状图、天平、写字板、喇叭、手机、文件夹、循环箭头、下划线；另有 `person()` 小人、`robot()` 机器人。需要更多手绘组件时查 `motion_index.py search 手绘`，HyperFrames 的 `hf:hw-*` 系列可以直接引入。

## 4. 录屏与白板衔接：手绘显示器

```text
白板 → 录屏：monitor(..., img=录屏首帧) → 镜头 dive 到显示器矩形 → 正好铺满时硬切到 screen_clip
录屏 → 白板：screen_clip 结束 → 新世界里 monitor(..., img=录屏末帧) → 镜头 set 在显示器矩形 → emerge 拉出
```

- 首帧、末帧用 `comp.still_at(片段, 媒体时间)` 按精确帧号抽取（`select=gte(n, 帧号)`）。
- **录屏镜头在结束前至少 1 秒回到全画幅**，否则显示器里的末帧与录屏最后画面对不上。
- 录屏镜头里的推近和标注（框、圈、下划线、叉）写在 1920×1080 视频坐标里。素材在滚动时框容易错位，只在画面静止段画框，其余用 `sticky()` 便签说明。

## 5. 视频卡片贴在白板上（开场混剪等）

- `video_card(名称, x, y, 开始, 结束, rot)`：卡片贴在当前世界上，平时显示首帧，播放期间是真实视频（外层容器每帧跟随镜头的位移、旋转、缩放），播完换成末帧。素材放在 `comp/assets/cards/<名称>.mp4`、`.m4a`、`_first.png`、`_last.png`。
- 节奏参考：开头从宽画面快速甩进第一张卡；每张播放时缓慢推近；在一段结束前约 0.25 秒开始甩向下一张，甩 0.5 秒；全部播完后拉远看全景，再甩进正文第一块白板。
- 卡片排成两行之字形，带轻微旋转和胶带。

## 6. 圆形人像

- `face(视频, 开始, 结束)` 定义人像出现的时段；人像是右下角的圆形小窗（640px 圆按 0.47 缩放，约 300px，白边加蓝圈）。
- `emphasis(开始, 结束)` 在讲重点时放大到原尺寸（back.out 缓动）。全片放大次数按重点数量定，那部 7 分钟的片子约 10 处。
- 人像窗在最后一个字说完时淡出，不留空的灰圈。
- **安全区**：广角镜头时右下约 330×330 像素不放白板内容，否则会被人像挡住。

## 7. 角色或岗位动画（8–15 秒）

口播出现"某 Agent / 某岗位负责……""它会……"这类介绍句时，建议插一段白板动画：

1. 固定开头 `role_head()`：机器人 + 名称 + 蓝色下划线 + 一句灰色副标题。
2. 之后口播里每个"动作词"出一个手绘元素，时刻用 cue 引用对齐到那个词。
3. 结果没有实际跑出来的，写"这次还没跑""待真实询价"，不编造结果（核心原则 4）。

已用过的配方作为手法卡保存在手法库里，按内容检索复用。

## 8. 时间、构建与检查

- 所有时刻用 [时间引用](timeline.md#时间引用) 解析：`T = Timing(edit)`，`C = lambda 文本, 段=None, 偏移=0: T.seconds({...})`。开场长度或剪辑一变，重跑构建脚本即可。
- 构建脚本放在项目 `edit/scripts/`，`sys.path` 加入 `<skill>/scripts` 和本模板目录后 `from wb_lib import Comp`。
- 字体用手写体（如站酷快乐体），文案改完运行 `media_tools.py fontcheck` 检查缺字；→ 已由库自动换成内联 SVG。
- HyperFrames 流程见 [制作路线与合成](production.md#hyperframes)：`check` → `snapshot --at` → 整片 `render`。截图时刻至少覆盖：每个世界的切换点、每次衔接前后 0.1 秒、每次人像放大、每段角色动画中点。
- `check` 会提示"世界越出容器"等布局信息，这是设计如此（世界比画面大），模板已标记为允许越界。
- **黑帧风险**：`check` 若提示"heavy overlay 元素过多"（模糊、渐变、clip-path 元素合计接近 40 个），上游反馈渲染开头可能出现黑帧。整片渲染后先看开头几秒；出现黑帧时把较长的白板段拆成多个子合成再拼接。
- 先用完整风格做前 60–90 秒参考片给用户确认（生成脚本把总时长截短），确认后再铺全片。
