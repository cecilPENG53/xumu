# 输入与旁白

## 视频

- 先读当前 Video Use 的 SKILL.md，再用它转录和剪辑；helper 参数以 `--help` 和实现为准。
- 探测分辨率、时长、帧率、声道与旋转。混合帧率先定交付帧率；竖屏交付重新构图。
- 保留逐字 ASR（含停顿、语气词、重录信号）。有缓存且源文件未变就复用；云端转录使用已授权的服务。
- 记录素材路径、片段实例 ID、原片起止与剪后起点。剪点对齐词边界，留合理边缘，加短音频淡入淡出。
- 原片可作全片背景，B-roll 与动画只覆盖需要的时段。主剪辑锁定后生成字幕和 `visual-plan.json`。

## 音频

- 确认原声保留范围或用户允许的剪辑策略，保住语气、节奏与人物意图。
- 转录、选段、短淡入淡出后生成旁白母带，复核新时间戳。
- 先确认 Video Use helper 是否支持纯音频；不支持时用 FFmpeg 提取拼接，并保存片段映射。
- 画面覆盖全片：连续插画、录屏、图解、设计背景加文字都可以，一句话不必对应一个镜头。数字人在用户要求时加入。
- 母带是唯一主旁白；B-roll 与生成片段的自带人声静音。

## 文案

先判断它是"待改写脚本"还是"已有录音的逐字稿"。默认保留观点、事实与顺序；改写句子或扩写故事需用户授权，屏幕短文案另存。

- **原声**：先做结构与粗分镜，用户录音后再对齐。只有逐字稿时，时间戳标为估算。
- **合成旁白**：确认声音、语言、专有名词读法与预算，可先试听一小段。克隆声音需用户明确要求并具备授权。生成后检查错读、漏句，再锁时间。
- **无旁白**：字幕或音乐驱动，按阅读与动作时长排帧，记 `narration.kind=none`。

按估算语速得出的时长标为草案。`--ready` 前，实际音轨与帧级计划一致，字幕时间来自音轨对齐。

## 时间线修订

1. 源文件与转录缓存分开保存；旁白文件变化即触发时间线复核。
2. 同一片段重复使用时分配不同实例 ID。简单硬切用差值映射；变速、重叠转场、跨段动效显式重新映射。
3. 增删、变速、重排后递增 `timeline.revision`，重算受影响的镜头、字幕与 SFX。可复用的独立动画重新核对新窗口的长度与语义同步后再标状态。
4. 改色、局部改字等不动时间线的修改，只更新相应资产与验收记录。

## 最少启动问题

从已知信息补全，只问会实质改变结果的缺项：输入模式、[制作定位](production-profile.md) 各项、必须保留的内容、声音选择、外部生成预算与上传许可。定位不替代剪辑或配音授权；外部模型暂缺时，继续推进规划与代码镜头。
